Why waka

The dashboard tab you can finally close.

Everything WakaTime knows about your work, one command away. No browser, no context switch, no waiting.

01 · fast

Native & cached.

A single Rust binary with a per-profile local cache. Repeat queries come straight from disk; pass --no-cache when you want it fresh.

02 · beautiful

Made to be read.

Language-coloured bars with official Linguist colours, boxed headers, and a full-screen ratatui dashboard. It degrades gracefully with NO_COLOR.

03 · composable

Pipes welcome.

Table on a TTY, plain text when piped, or json, csv, tsv on demand. waka plays nicely with jq, spreadsheets and scripts.

Stats for any period

Today, yesterday, week, month, year or a custom range. Filter by --project.

todayyesterdayweekmonthyearrange --from --to

Keychain-first security

Your API key lives in the OS keychain (macOS Keychain, Windows Credential Manager, the Linux kernel keyring), with a 0600 file fallback. Switch between work and personal profiles with -p.

Reports

Export a productivity report to Markdown, HTML, JSON or CSV with report generate.

mdhtmljsoncsv

Goals that ping you

goals watch --notify refreshes in the background and sends a desktop notification when you hit a goal.

Self-maintaining

waka update pulls the latest release, config doctor diagnoses your setup, changelog shows what's new.

Lives in your workflow

Always on screen, never in the way.

waka prompt reads today's total from the local cache only. No network call, so it's safe to run on every prompt render.

Starship

A custom module in starship.toml.

~/code/my-saas on main ⏱ 6h 42m
❯
[custom.waka] command = "waka prompt 2>/dev/null" when = "true" style = "dimmed yellow"

tmux

One line in your status bar.

[0] 1:nvim* 2:zsh⏱ 6h 42m | 14:17
set -g status-right \ "#(waka prompt 2>/dev/null) | %H:%M"

Get started

Up and running in under a minute.

$ brew tap mouwaficbdr/waka $ brew install waka
$ curl -sSfL https://github.com/mouwaficbdr/waka/releases/latest/download/waka-v2.0.2-x86_64-unknown-linux-gnu.tar.gz \ | tar -xz && sudo mv waka /usr/local/bin/
# Grab the archive for your platform from https://github.com/mouwaficbdr/waka/releases/latest

The waka binary isn't published via cargo install; use Homebrew or a prebuilt release.

  1. waka auth login and paste your WakaTime API key. It goes straight to your OS keychain.
  2. waka stats today to see where your day went.
  3. waka dashboard and leave it running on a side monitor.

For Rust developers

Build on waka-api.

The HTTP client behind waka ships as a standalone, typed crate. Write your own WakaTime integrations without reinventing the API layer.

docs.rs/waka-api crates.io
# Cargo.toml [dependencies] waka-api = "1"
use waka_api::{WakaClient, SummaryParams}; let client = WakaClient::new("your-api-key"); let summary = client .summaries(SummaryParams::today()) .await?;
